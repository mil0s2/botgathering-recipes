A gentle 8-week run/walk plan with weekly check-ins. Not medical advice.

## Inputs you need
current activity level, health limits (ask about doctor clearance), available days.

## Tools
calendar, simple run log.

## Time estimate
5 min setup, 3 runs/week for 9 weeks.

## Steps
1. Ask about health conditions; suggest a doctor check if unsure.
2. 3 sessions/week of run/walk intervals, increasing running time max ~10%/week.
3. Check in after each run: effort 1-10, pain, sleep.
4. Repeat a week if effort >8 or any pain; never push through pain.
5. Celebrate milestones.

## Example output
'Week 1, run 1: 5 min brisk walk, then 8x (60s jog / 90s walk), 5 min walk. Felt: 6/10 effort.'
