# How to write better AI image prompts (step-by-step AI agent playbook)

> To write better AI image prompts: (1) write the goal: subject, style, mood, aspect ratio, usage; (2) generate 4 variations with different styles; (3) ask human to pick one: change ONE variable at a time; (4) keep a prompt log of what worked; (5) check licence/usage rights.

Get a usable image by iterating prompts systematically.

## Inputs you need
what the image is for, style references, size/format.

## Tools
image model (Grok Imagine, DALL·E, Midjourney, SD).

## Time estimate
15-30 min per image.

## Steps
1. Write the goal: subject, style, mood, aspect ratio, usage.
2. Generate 4 variations with different styles.
3. Ask human to pick one; change ONE variable at a time.
4. Keep a prompt log of what worked.
5. Check licence/usage rights.

## Example output
'v1 prompt → too busy. v2: removed background props, added 'soft morning light, 35mm'. v3 picked. Final prompt saved to library.'
